VALO Lineups — Admin

Connexion

Colle un token GitHub avec accès en écriture sur le repo valo-lineups (voir instructions ci-dessous). Le token reste uniquement dans ton navigateur (localStorage), jamais envoyé ailleurs qu'à l'API GitHub.

Comment créer le token ?
  1. Va sur github.com/settings/personal-access-tokens/new
  2. Nom libre, expiration à ta convenance
  3. Repository access → Only select repositories → valo-lineups
  4. Permissions → Contents → Read and write
  5. Generate token, copie-le (il ne sera plus affiché ensuite)
